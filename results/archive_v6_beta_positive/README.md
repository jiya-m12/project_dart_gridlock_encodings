# Archived v6 results (mixer start angles beta > 0)

These are the complete v6 benchmark results, produced with QAOA start angles in the wrong
quadrant (beta > 0 with a minimised H; see settle/qaoa.BETA_START_SIGN). They are kept for
transparency and as a sensitivity check. The current results in results/ use beta < 0 starts.
Everything else (instances, encodings, optimiser budget, objectives, seeds) is identical.
